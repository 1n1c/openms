# 武器攻击命中数据（hitbox rectangle + hit timing）

**数据来源**：本项目 catalog.json Character.wz extract

**rectangle** = Character.wz Afterimage/<afterImage>.img 中各攻击动作的碰撞矩形
  - left/top/right/bottom 是相对于角色身体中心(0,0)的像素偏移
  - 正值 right/bottom = 角色右侧/下方, 负值 = 左侧/上方
  - weaponType 的 hit group 决定 hit.img 用 sword1/sword2 还是 mace1/mace2

**timing.release** = 原版 hit 判定时机（从动作开始到命中窗口的原始时间点，未缩放）
